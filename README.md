## 어려웠던 점 3가지와 해결
1. 박스오피스 순위가 올라갔는지 내려갔는지 표시할 때 모양을 넣는 방법이 헷갈렸는데, CSS 글자 꾸미기를 사용해서 화살표 모양을 넣어서 해결했습니다.
2. 화면 크기를 줄이거나 늘릴 때 영화 카드가 줄 맞춰서 예쁘게 안 바뀌었는데, CSS 파일 맨 아래쪽에 화면 크기별 규칙을 적어주어서 해결했습니다.
3. 상세 페이지 뒤에 배경 그림을 넣을 때 글씨가 잘 안 보여서, 배경 그림을 살짝 어둡게 만드는 꾸미기를 같이 넣어서 해결했습니다.
